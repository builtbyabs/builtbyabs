## 📦 Featured Projects

### **[shopify-geo-audit](https://github.com/builtbyabs/shopify-geo-audit)**
> Audit your Shopify store for AI-search readiness in seconds

A powerful CLI tool that analyzes how AI search engines see your store, scores visibility (0-100), and generates actionable fixes.

**Features:**
- Checks what ChatGPT, Perplexity, Gemini & Google AI Overviews can read
- Generates structured data, `llms.txt`, and `robots.txt` recommendations
- No signup required, runs locally
- Built with TypeScript & Node.js

**Languages:** TypeScript · Node.js · JSON-LD · Schema.org
